# Weather Application

A web application built with HTML, CSS and JavaScript that retrieves weather data from an external API to display current weather conditions and forecasts.

## Overview

This project demonstrates my ability to work with external APIs, retrieve and display dynamic data, and build an interactive web application.

## Features

- Retrieve weather data from an external API.
- Display current weather conditions.
- Show weather forecasts.
- Present weather information through a user interface.
- Allow users to interact with the application to view weather information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- External Weather API
